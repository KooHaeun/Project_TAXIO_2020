# TAXIO(타시오) — 택시 투어 예약 플랫폼

지역마다 흩어진 택시 투어 예약을 한 앱으로 모은 **승객–기사 양방향 예약** 안드로이드 앱입니다.
명지전문대학 컴퓨터공학과 졸업작품(2020, 4인 팀)이며, 원본 저장소는 [MoonGahee/Project_TAXIO_2020](https://github.com/MoonGahee/Project_TAXIO_2020)입니다.

- **수상**: 컴퓨터공학과 졸업작품 전시회 **대상**, 교내 캡스톤디자인 경진대회 공학부문 **은상**
- **논문**: 모빌리티 시장 속 새로운 비단길, 'TAXIO(타시오)'. 한국컴퓨터정보학회 동계학술대회 논문집 29(1), 2021 (1저자)

![TAXIO 승객·기사 앱 화면](assets/screens.jpg)

## 주요 기능

- **양방향 예약**: 승객이 날짜·조건으로 기사를 골라 요청하고, 기사가 일정을 승인
- **앱 내 채팅**: Firebase 실시간 채팅으로 연락처 공개 없이 소통
- **여행 도우미**: Google Maps·Places API 경로 거리 측정, OpenWeatherMap 날씨와 체감온도별 옷차림 추천
- **쉬운 화면**: 연령대와 관계없이 쓰도록 한글로 직관적으로 표시


## 기술 스택

Android(Java), Firebase, Google Maps API, Google Places API, OpenWeatherMap API
